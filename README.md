# Horario WS 2026/27 — Angie Moreno Trevejo

Schedule viewer for the Winter Semester 2026/27 at Universität Bonn.  
M.Sc. Geowissenschaften (Geochemie/Petrologie) — Campus Poppelsdorf.

## Features

- Weekly grid with all registered courses
- Dark mode support (follows system preference)
- Timezone toggle: Bonn (CEST) ↔ Lima (PET)
- Overlap detection highlighted on Tuesday
- Mobile responsive
- No dependencies — vanilla HTML/CSS/JS
